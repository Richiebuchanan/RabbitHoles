How these are built

Every site follows the same method, built together with Claude, Anthropic's AI model.

  1. Scheduled research. A recurring task searches a fixed list of sources and watchlists.
  2. Scoring. Each item is graded for relevance and for how strong its evidence is.
  3. Sourced analysis. Conclusions are rewritten only when the evidence clears a set bar, and every claim links to its source.
  4. One database. Each site is a set of static pages reading from a shared Postgres database, so pages update themselves.

The takeaways, counts and dates on this page are read live from that same database.
